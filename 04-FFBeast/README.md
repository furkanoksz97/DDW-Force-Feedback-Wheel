\# FFBeast



\*\*FFBeast\*\* was used as the Force Feedback software and firmware platform for this project.



It provides the interface between the steering system and the games, allowing the Direct Drive motor to produce Force Feedback effects.



In this project, FFBeast was used together with the \*\*ODrive S Mini, BLDC motor and rotary encoder\*\* to create the Force Feedback steering system.



For detailed information about FFBeast, firmware, configuration and DIY Force Feedback wheels, refer to the official documentation:



\[FFBeast Official Documentation] https://ffbeast.github.io/
