# Testing

After completing the hardware and software integration, the Direct Drive system was tested in racing games.

The complete system was tested as a single sim racing setup, including:

* Direct Drive steering
* Force Feedback
* Rotary encoder
* Logitech G27 pedals
* Logitech G27 shifter
* Pro Micro shifter controller

## Test Results

The system was tested in multiple racing games.

Steering, Force Feedback, throttle, brake, clutch and gear selection operated correctly during testing.

The completed system successfully functioned as a custom Direct Drive sim racing setup.

## Final Status

**Project Status: Working**

The current version of the system has been successfully assembled and tested in games.

Further development and improvements may be added to the project in the future.
